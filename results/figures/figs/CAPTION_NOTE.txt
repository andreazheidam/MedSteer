CSR and DSE rows use one colour scale per case, shared across prompts (1st-99th percentile in the image region; diverging and centred at 0 only where values take both signs). Map rows use per-panel scales and show only where each map responds; their brightness must not be compared between prompts. *First column: SteerViT and DINOv2 rows receive no text input; CLIP and SAM3 rows receive the empty string "" (empty-text control), since both models require a text input.
